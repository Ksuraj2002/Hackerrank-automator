# Day 8 - for loop

## Classwork: List Every Factor of N
**Problem Statement**
A factor (divisor) of `N` is a positive integer that divides `N` leaving no remainder. For `N = 12` the factors are `1 2 3 4 6 12`.

Given a positive integer `N`, print all of its factors in increasing order on a single line, separated by single spaces.

The direct solution tests every candidate from `1` to `N` with `N % i == 0`, which costs `O(N)`. Once that works, try the `O(sqrt(N))` improvement: whenever `i` divides `N`, both `i` and `N / i` are factors - collect both and sort before printing. Careful with perfect squares, where `i` and `N / i` coincide.

**Input Format**
A single line containing one integer `N`.

**Output Format**
A single line with all factors of `N` in increasing order, separated by a single space.

**Constraints**
- `1 <= N <= 10^6`
- Time Complexity: `O(sqrt(N))` expected, `O(N)` accepted
- Space Complexity: `O(number of factors)`

**Sample Input 0**
```
12
```

**Sample Output 0**
```
1 2 3 4 6 12
```

## Classwork: Reverse the Digits of an Integer
**Problem Statement**

# Day 40 - Maximum subarray (Kadane)

## Classwork: Maximum Subarray Sum (Kadane)
**Problem Statement**
**LeetCode LC53** - original problem: https://leetcode.com/problems/maximum-subarray/

Given an integer array `A` of size `N`, find the contiguous subarray containing at least one element that has the largest sum, and print that sum.

A *subarray* is a run of consecutive elements: `[2, 3, 4]` is a subarray of `[1, 2, 3, 4, 5]`, but `[1, 3, 5]` is not.

The array may contain negative numbers, and it may be **entirely** negative. Because the chosen subarray must be non-empty, the answer for an all-negative array is its largest (least negative) element - not `0`. That edge case is the one most submissions get wrong.

Kadane's algorithm solves this in a single pass. Walk left to right holding `cur`, the best sum of a subarray ending at the current index. At each element either extend the previous run or start a new one - `cur = max(A[i], cur + A[i])` - and keep the largest `cur` ever seen.

**Input Format**
- The first line contains an integer `N`, the size of the array.
- The second line contains `N` space-separated integers, the elements of `A`.

**Output Format**
A single line containing the maximum subarray sum.

**Constraints**
- `1 <= N <= 10^5`
- `-10^4 <= A[i] <= 10^4`
- Time Complexity: `O(N)`
- Space Complexity: `O(1)`

**Sample Input 0**
```
9
-2 1 -3 4 -1 2 1 -5 4
```

**Sample Output 0**
```
6
```

1
