## Homework: Print Vector Elements
**Problem Statement**
You are given `N` integers. Print each integer on its own line, in the order they were given.

**Input Format**
- Line 1: an integer `N`.
- Line 2: `N` space-separated integers `a_1, ..., a_N`.

**Output Format**
`N` lines. The i-th line contains `a_i`.

**Constraints**
- `1 <= N <= 100000`
- `-10^9 <= a_i <= 10^9`

**Sample Input 0**
```
3
1 2 3
```

**Sample Output 0**
```
1
2
3
```
