**Problem Statement**
Given a letter grid and a list of words, print every word that can be spelt in the grid by moving between adjacent cells, using each cell at most once per word.

You can also try this problem on: [LeetCode 212 - Word Search II](https://leetcode.com/problems/word-search-ii/).

**Input Format**
The first line contains `m` and `n`. Each of the next `m` lines contains `n` letters with no spaces. The next line contains `k`, then a line of `k` space-separated words.

**Output Format**
A single line: the found words in lexicographic order, space separated. Empty line if none.

**Constraints**
- `1 <= m, n <= 6`
- `1 <= k <= 20`

2
oath pea

oath
