## Classwork: Build a 3-node binary tree manually and print root, left, right
**Problem Statement**
You are given three integers that form a binary tree with a root, a left child and a right child in that order. Print them on three separate lines: the root first, then the left child, then the right child.

**Input Format**
A single line with three integers separated by spaces: the root value, the left child's value and the right child's value.

**Output Format**
Three lines: the root value on line 1, the left child's value on line 2, the right child's value on line 3.

**Constraints**
- `-10^4 <= each value <= 10^4`

**Sample Input 1**
```
1 2 3
```

**Sample Output 1**
```
1
2
3
```

**Sample Explanation 1**
The three inputs `1 2 3` are the root, left child, and right child in that order. Each one is printed on its own line.

**Sample Explanation 2**
